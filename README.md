# Moldev_ide — instaladores

IDE leve para Windows, feita em Rust: árvore de arquivos com Git, editor com cores de sintaxe e terminais em abas com painéis divididos.

## Instalar

1. Abra a página de [Releases](https://github.com/PaulojTelli/moldev_ide-releases/releases/latest).
2. Baixe `Moldev_ide-Setup-<versão>.exe` e execute.

Não precisa de administrador. A IDE é instalada para o seu usuário, com atalho no Menu Iniciar e, se você marcar, "Abrir com Moldev_ide" no botão direito das pastas.

O Windows pode mostrar o aviso do SmartScreen porque o instalador não é assinado: clique em "Mais informações" → "Executar assim mesmo".

## Atualizações

Ao abrir, a IDE verifica as Releases deste repositório e oferece atualizar quando houver versão nova.

Este repositório contém apenas os instaladores; o código-fonte é mantido em outro lugar.
